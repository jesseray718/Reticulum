# Reticulum

**Cryptographic, resilient, delay-tolerant networking stack (fork / working copy within the OpenRoot lattice).**

## What this is
Reticulum provides encrypted, multi-hop, offline-capable networking that works over many physical media (LoRa, serial, TCP, etc.). It is designed for intermittent connectivity and low bandwidth.

## Role in the Lattice
Communications substrate. Enables nodes to exchange data, announces, and messages without relying on continuous internet or central servers.

## Bigger Picture
Any real offline-first infrastructure needs a communication plane that still functions when the grid and conventional networks are unavailable. Reticulum supplies that plane for the OpenRoot lattice.

## Current Status
Active working copy / integration point within the wider lattice.
